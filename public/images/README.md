# Photography & brand logos

## Required photos (do not use AI portraits)

- `hero/maham-hero.jpg` - professional / on-camera hero portrait
- `about/maham-about.jpg` - natural / candid about photograph

Until these files exist, the UI shows an intentional editable placeholder.

## Brand logos (optional)

Add grayscale-friendly SVG/PNG files under `brands/` and set each brand's `logo` field in `src/content/brands.ts`.

## Open Graph

Dynamic OG image is generated at `/opengraph-image`. Optional static fallback: `og/og-default.jpg`.
